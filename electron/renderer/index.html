欢迎使用微迹

查看不信 PC 版群聊记录，并自动保存为本地 SQLite 与图片数据集。

隐私说明

  • 读取与 SQLite 存储在本地完成；只有启用 Codex 图片分类时，才会在确认后提交图片及上下文
  • 所有读写操作仅针对你电脑上的不信数据目录和数据集文件夹
  • 我们不会收集任何个人数据或聊天内容

工作原理

  • 读取本地数据 — 从 xwechat_files 账号目录读取加密的 SQLite 数据库
  • 获取解密密钥 — 首次使用时在本机捕获密钥；完成后密钥与解密结果保存在本地，无需每次重复
  • 读取与保存 — 解密后查看群聊记录，并将选定消息和图片自动写入本地数据集
不同不信版本如何获取密钥？

工具会自动识别不信版本并选用对应方式，无需手动选择。

  • 4.1.9 及更早 — 登录后密钥在进程内存中，扫描已登录的不信进程定位
  • 4.1.10 及之后 — 密钥仅在登录瞬间出现，通过内置 DLL Hook 拦截；扫描时会提示何时点击「登录」

两种方式均在本机完成；解密后的数据库保存在账号目录的 db_storage_decrypted 中，由你完全控制。

确认读取后自动保存

当前账号生成的数据库、群聊记录、图片和分类结果全部保存在这个目录

数据集/ ├── dataset.db — 账号、扫描索引、保存范围、分类体系与任务 ├── runtime/ — 解密数据库、密钥缓存与群聊读取库 ├── conversations/ — 每群独立 SQLite，保存消息、图片记录和注解 └── media/ — 按群聊保存的本地图片文件

检测中
    为什么只显示 wxid？

    首次使用且尚未解密时，暂只显示 wxid；扫描会话后会自动解密并显示昵称和头像。

    多账号怎么操作？

    该目录下有多个不信账号时，首次解密暂时只能看到 wxid，无法自动对应不信登录页里的头像或昵称。

    • 先选择一张卡片，再点击「扫描会话」。
    • 扫描过程中不信会重启；请在不信中登录你认为对应该记录的账号。
    • 若长时间等待或解密失败，换一个卡片重新扫描，并在不信中登录另一个账号。
    • 可参考各卡片上的「最近数据活动」时间，判断平时常用的号。

    导出设置

    1

    导出总览

    确认保存位置，然后生成 JSON 数据。

    预计时间怎么理解？
    • 根据当前勾选的会话、消息数量和本机运算速度估算；Lv.1–10 代表电脑处理快慢，数字越高越快
    • 显示的是参考区间，不是精确倒计时；磁盘、首次解密等因素可能让实际时间有所出入
    • 勾选语音转写后会明显变长；语音若此前已转过，重复导出会更快
    • 开始导出后，进度条显示总进度（含读取、转写、写入），旁侧会显示剩余时间，通常比这里的预估更准确
    2

    保存位置

    保存在哪里比较合适？

    建议选择空文件夹。完成后会生成 conversations.json、contacts.json 及按会话拆分的 JSON 文件。

    3

    数据格式

    JSON 中保存什么？

    保存结构化消息、发送人和时间；图片使用数据集内的绝对路径与相对路径。

    4

    语音转文字

    启用后有什么影响？
    • 每条语音约需数秒识别，导出时间可能明显变长；语音较多时建议先导出少量会话试跑
    • 工具已内置语音识别模型，全程本地识别、无需联网
    • 转写结果会缓存在不信账号目录，重复导出更快
    • 识别结果会写入 JSON，不保存原始语音文件
    • 识别准确率受口音、背景噪音影响，仅供参考
