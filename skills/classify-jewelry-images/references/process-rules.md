# Process Rules

- Assign a process only when the image, readable text, or nearby chat gives direct support.
- Do not infer a process from color alone.
- Return `none` only when the item is jewelry and clearly has no matching approved process.
- Return `uncertain` when the item is jewelry but the approved process cannot be determined.
- Keep this file limited to reviewed process rules; add stronger visual rules only after human validation.
- Treat candidate rules from the learning database as lower priority until a human promotes them here.
